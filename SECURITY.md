# Security Policy

ElmaGo güvenlik bildirimleri için `destek@elmago.com.tr` adresini kullanın.

Lütfen güvenlik açıklarını herkese açık issue olarak paylaşmayın. Bildirime etkilenen bölüm, tekrar üretme adımları ve mümkünse ekran görüntüsü ekleyin. Parola, erişim anahtarı, kullanıcı mesajı veya kişisel veri göndermeyin.

Desteklenen sürüm, TestFlight ve canlı web sitesinde yayımlanan en güncel sürümdür.
